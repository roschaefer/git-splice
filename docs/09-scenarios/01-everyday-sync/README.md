# Everyday sync

The states a splice goes through with everyday pulls and pushes.

- [sync-model](01-sync-model/README.md): the state the README and the
  sync model draw. Both sides moved on since the clone.
- [up-to-date](02-up-to-date/README.md): a splice freshly cloned and not
  touched since, and the states one change on either side leads to.
- [many-splices](03-many-splices/README.md): five splices, each in a
  different state.
- [never-fetched](04-never-fetched/README.md): a fresh clone of the
  monorepo that hasn't fetched the upstream yet.
