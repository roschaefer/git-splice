# Rewritten history

Commits that were rewritten after a sync: edited, rebased or rebuilt.

- [edited-before-push](01-edited-before-push/README.md): commits reworded
  before `push --rebuilt-commit`.
- [upstream-rewritten-equal-tree](02-upstream-rewritten-equal-tree/README.md):
  the upstream force-pushed a commit with the same files.
- [diverged-unrelated-history](03-diverged-unrelated-history/README.md):
  the upstream was rebuilt from scratch, and shares no history with the
  splice.
- [patch-branch-rebased](04-patch-branch-rebased/README.md): a fork
  rebases the patch branch the monorepo follows.
